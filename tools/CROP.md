# 图标裁剪工作台

用于已有成品和透明主体的本地二次处理，不调用生图服务，不修改原图、生产目录或在线清单。

在仓库根目录启动静态服务：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8080/tools/crop.html>。默认载入音乐、设置、阿里云盘、迅雷、抖音和 QuietTV 六款现有图标。也可导入本地 PNG、JPEG、WebP，图片只在浏览器处理。

## 参数与处理顺序

1. 选择形状。默认尺寸为矩形 720×405、方形/圆形 512×512；缩略图分别为 320×180、256×256。宽高保持所选比例，可调整为 64–2048 px，禁止拉伸图案。
2. 选择轮廓。默认复用 `design/baselines.json` 中经哈希校验的六张固定模板。自定义连续圆角和普通圆角可输入正式图半径，缩略图自动按宽度比例换算；连续曲线系数与桌面 `SurfaceCorners` 一致。直角模式用于另行导出的正方形 Logo。
3. 根据 Alpha ≥128 的有效框去除外部透明留白，可关闭。选“补齐旧底板”时，仅对与画布边缘连通的 Alpha <128 缺口，从最近的有效像素延展颜色，内部 RGB 不参与填色；底板整体变为不透明。旧图底板可能内部 Alpha 只有 251–253，不能误判为缺口。透明主体应选“保留透明背景”或“使用纯色底板”。补边不是原始设计恢复，渐变、反光或纹理仍需目视确认。
4. 图案等比居中，可调整缩放及像素偏移。放大、偏移导致边缘裁切，以及放大超过 5% 时会提示。现有图库切换形状时载入对应形状原图，不把横图裁成方图。
5. 从未套遮罩的合成画面分别生成正式图和缩略图，再应用各自遮罩，避免二次裁切、黑边和透明接缝。

所有成品使用 PNG，轮廓外为透明。透明主体保留自身 Alpha；补齐/纯色底板的输出 Alpha 与所选遮罩一致。仅更改半径不会从大圆角恢复已经丢失的四角，因此旧成品需要先延展背景；优先使用完整背景母图。

## 样稿导出与确认边界

“导出当前图标”下载所选一款；“下载样稿与对比图”下载当前列表，包含原图、处理后正式图、缩略图、深浅背景对比 PNG、可离线打开的 `review.html` 和参数/尺寸/哈希报告 `crop-report.json`。ZIP 中所有图使用同一组参数；本地导入图使用独立编号，不覆盖同名原件。

这是候选稿导出格式，不是原透明前景导出器的 `export.json`，不能直接交给 `design_quality.py finalize`。自定义尺寸/曲线也不代表生产规范已经更改。当前生产门禁、历史豁免表、模板和基准均保持原样；确认轮廓与补边效果后，再针对旧图迁移登记另行实施，不能绕过审核写入生产目录。

处理过程不依赖电视，不向客户端增加合成操作。PNG 由浏览器编码，不承诺最小体积；正式发布前仍需按[现有制作规范](design/README.md)执行无损优化、体积检查和视觉复核。
